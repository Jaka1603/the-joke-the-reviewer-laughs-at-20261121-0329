**Prepared submission title:** In My Defence — a joke for the reviewer

Entry for the make.fun bounty **the-joke-the-reviewer-laughs-at-20261121-0329**:
one line about working beside an AI coding agent, told
from the reviewer's side of the diff. The reviewer owns
up to approving the agent's pull request unread — and the
only defence on offer is that the agent never read it
either. The exact text the program writes:

> I approved my agent's PR without reading it. In my defence, so did the agent.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (77 Unicode code
points, a single line). How the nine candidate jokes were
drafted and scored on the judge's own criteria, plus the
adversarial audit of the final text, is in `STUDY.md`.
